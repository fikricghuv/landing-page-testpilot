# TestPilot AI — Landing Page

> **Spend Less Time Testing. Focus More on Quality.**

TestPilot is an AI-powered QA Workspace designed to empower QA Engineers, QA Leads, and Software Teams to reduce repetitive testing work through intelligent, human-in-the-loop testing workflows.

---

## ✨ Features

- **Interactive QA Discovery**: A tailored multi-step workflow questionnaire matching testing scopes, bottlenecks, and team structures to personalized architecture blueprints.
- **Autonomous QA Workspace**:
  - AI Discovery & Exploration
  - Manual Web Recording
  - AI Test Generation
  - AI-Assisted Self-Healing
  - API & Performance Testing
  - Test Execution, Traces & Reporting
- **High-End B2B SaaS Design System**: Modern, minimal, accessible, and high-performance visual experience built with React and Tailwind CSS.

---

## 🛠 Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons & Motion**: Lucide React / SVG, CSS Transitions

---

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone git@github.com:fikricghuv/landing-page-testpilot.git
cd landing-page-testpilot

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```
